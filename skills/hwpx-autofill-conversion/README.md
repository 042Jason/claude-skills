# hwpx-autofill-conversion

한컴 한글 **`.hwpx`** 양식 파일을 첨부하면, 그 양식의 XML 구조를 그대로 보존한 채 사용자가 입력한 **주제·내용**으로 본문을 자동 채워주는 Claude 스킬입니다.

## 무엇을 하나요

1. 첨부된 `.hwpx`를 ZIP으로 해제하고 내부 XML 구조를 분류·이해합니다.
2. 페이지(섹션) 단위로 본문 영역을 식별합니다.
3. 사용자가 요청한 **주제**에 맞춰 텍스트 노드(`<hp:t>` 등)를 채워 넣습니다.
4. 헤더/스타일 정의(`header.xml`, `content.hpf` 등)는 **건드리지 않고** 그대로 유지합니다.
5. 결과를 다시 `.hwpx` 패키지로 묶어 산출합니다 (필수).

## 트리거 예시

다음과 같은 요청이 들어오면 자동으로 발동됩니다.

- "첨부한 hwpx 양식 그대로 '청년 창업 지원 사업 계획서'로 채워줘"
- "이 보고서 hwpx 형식 유지하고 주제만 바꿔서 작성해줘"
- "양식은 hwpx 첨부한 것 쓰고, 내용은 ○○○로"

## HWPX 파일 구조 요약

이 스킬이 다루는 한글 `.hwpx` 패키지의 핵심 구조는 다음과 같습니다.

### 최상위 구조

- **`mimetype`** — `application/hwp+zip` 으로 HWPX 패키지임을 명시
- **`META-INF/manifest.xml`** — 내부 모든 파일의 경로와 MIME 타입 정의
- **`BinData/`** — 이미지·도형·OLE 등 바이너리 자원
- **`Preview/`** — 썸네일 미리보기(`PrvImage.png`, `PrvText.txt`)

### Contents/ 폴더 (핵심)

| 파일 | 역할 |
|---|---|
| `content.hpf` | 패키지 명세서 (메타데이터, 매니페스트, Spine 읽기 순서) |
| `header.xml` | 글꼴·문단·글자·표 스타일 등 서식 정의 — 본문은 ID로 참조 |
| `section0.xml`, `section1.xml`, … | **실제 본문 텍스트와 객체** (구역마다 파일 증가) |
| `settings.xml` | 보기 배율·호환성·기본 언어 등 환경 설정 |

본문 텍스트는 주로 `<hp:p>`(문단) 내부 `<hp:t>`(텍스트 런) 태그에 들어 있으며, 이 스킬은 이 텍스트 노드를 안전하게 치환하는 방식으로 동작합니다.

## 사용 흐름

```text
[1] 사용자: hwpx 파일 첨부 + "이 양식으로 ○○○ 보고서 만들어줘"
       │
       ▼
[2] Claude: .hwpx 압축 해제 → Contents/section*.xml 파싱
       │
       ▼
[3] 주제에 맞춰 텍스트 노드 작성/치환 (스타일 ID는 유지)
       │
       ▼
[4] 수정된 XML을 다시 zip → 확장자 .hwpx 로 재패키징
       │
       ▼
[5] 결과 .hwpx 파일 제공
```

## 주의사항

- **스타일 ID는 절대 변경하지 않습니다.** `header.xml`의 글꼴/문단 정의가 깨지면 한글에서 양식이 망가져 보입니다.
- **표/이미지 위치**는 원본 양식을 그대로 보존합니다. 필요한 경우 셀 내부 텍스트만 교체합니다.
- 결과 파일은 반드시 `.hwpx` (ZIP 컨테이너) 로 다시 패키징되어야 합니다.
- 일부 매크로·OLE 객체는 그대로 보존되며, 내용을 새로 생성하지 않습니다.
